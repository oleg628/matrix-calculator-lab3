# Matrix Calculator — лабораторная работа №3

Кроссплатформенная библиотека для работы с матрицами на C++17: базовые
операции, индивидуальное задание №25, модульные тесты GoogleTest, документация
Doxygen, Docker-контейнер и CI/CD в GitHub Actions.

![CI](https://github.com/oleg628/matrix-calculator-lab3/actions/workflows/ci.yml/badge.svg)

## Вариант 25

**Создание матрицы из одномерного массива.** Функция
`matrix_from_array(const double* data, int rows, int cols)` копирует
`rows * cols` элементов в новую матрицу построчно. Исходный массив не
изменяется, а полученная матрица владеет собственной памятью.

## Возможности библиотеки

| Функция | Назначение |
|---|---|
| `create_matrix(rows, cols)` | создаёт матрицу, заполненную нулями |
| `free_matrix(matrix)` | освобождает память и обнуляет структуру |
| `matrix_add(a, b)` | поэлементное сложение матриц |
| `matrix_multiply(a, b)` | матричное умножение |
| `matrix_from_array(data, rows, cols)` | создание матрицы из одномерного массива (вариант 25) |
| `print_matrix(matrix)` | форматированный вывод, сокращение больших матриц |

## Сборка и запуск

Требуются CMake 3.20+, компилятор с поддержкой C++17 и интернет для первой
загрузки GoogleTest через `FetchContent`.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
./build/matrix_calculator
./build/variant_25
```

Сборка выполняется с `-Wall -Wextra -Wpedantic -Werror` (для MSVC —
`/W4 /WX`).

## Тестирование

```bash
ctest --test-dir build --output-on-failure
```

Проверяются сценарии:

1. создание матрицы и инициализация нулями;
2. сложение матриц;
3. умножение квадратных матриц;
4. умножение вектор-строки на вектор-столбец;
5. создание матрицы из массива и построчный порядок копирования;
6. независимость матрицы от исходного массива;
7. матрица 1×1;
8. ошибки при нулевых и отрицательных размерах;
9. ошибка при `nullptr` в `matrix_from_array`;
10. несовпадение размеров при сложении и умножении;
11. безопасное повторное освобождение пустой матрицы.

Проверка утечек памяти:

```bash
valgrind --leak-check=full --error-exitcode=1 ./build/tests/matrix_tests
```

## Обработка ошибок

В проекте используются исключения:

- `std::invalid_argument` — неположительные размеры, пустая матрица,
  несовместимые размерности, `nullptr` вместо массива;
- `std::bad_alloc` — нехватка памяти при создании матрицы.

`free_matrix` принимает `Matrix&`, а не `Matrix` по значению. Это осознанное
улучшение относительно примера из методических указаний: после освобождения
указатель вызывающей стороны обнуляется, поэтому повторный вызов не приводит
к double free и use-after-free.

## Docker

```bash
docker build -t matrix-calculator .
docker run --rm matrix-calculator
```

Dockerfile использует многоэтапную сборку: в первом образе устанавливаются
CMake и g++, во втором остаётся только собранный исполняемый файл.

## CI/CD

Workflow `.github/workflows/ci.yml` при каждом push и pull request:

1. устанавливает CMake, g++, Doxygen, Graphviz и Valgrind;
2. собирает проект в Debug;
3. запускает CTest;
4. проверяет утечки через Valgrind;
5. генерирует HTML-документацию и выгружает её как артефакт;
6. собирает Docker-образ и запускает контейнер.
